czech-file-knife

Czech File Knife (CFK): Rust tool treating local, cloud, distributed, and exotic storage backends as one unified filesystem; crate family spans core types, CLI (ls/cp/mv/rm/cat/mkdir/stat), providers, cache, Tantivy search, FUSE VFS, TUI, and integrations (aria2, agrep, pandoc).

This site is served from the www/public/ category of the repository's site-operations bundle. Operational material (DNS, TLS, headers, profiles, tests, runbooks) is deliberately not part of the published surface.
